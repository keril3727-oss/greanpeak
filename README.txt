GREEN PEAK — PREMIUM UI BUILD

Что внутри:
- Адаптивный интерфейс для телефона, планшета и компьютера.
- Разделы: обзор, финансы, склад, клиенты, документы, аналитика, планирование, настройки.
- Демонстрационные данные (помечены как демо).
- Добавление финансовых операций и задач с сохранением в localStorage браузера.
- Экспорт финансовых операций в CSV.
- Подключение Supabase Auth с публичным Publishable key.

ВАЖНО:
Это улучшенная интерфейсная демо-версия, а не готовая полноценная ERP/CRM.
Новые операции и задачи пока сохраняются только на устройстве/в браузере, где они добавлены.
Данные склада, клиентов, документов и аналитики в этой версии — примеры интерфейса.
Supabase используется только для регистрации/входа; синхронизация бизнес-данных, таблицы БД и RLS ещё не реализованы.
Для публикации загрузите содержимое ZIP в новый deployment Vercel или замените файлы текущего проекта.
Файлы: index.html, style.css, app.js, README.txt
